## Agent skills

### Issue tracker

Issues and PRDs are tracked as local markdown files under .scratch/<feature-slug>/ using per-feature folders, numbered issue files, and in-file status fields. See docs/agents/issue-tracker.md.

### Triage labels

The repository uses the canonical five-role triage vocabulary with default label strings unchanged. See docs/agents/triage-labels.md.

### Domain docs

This repository is configured as single-context: root-level CONTEXT.md and docs/adr/ are the primary domain sources. See docs/agents/domain.md.

# 微信小程序阈值初版配置表（V1）

## 1. 使用原则
1. 所有阈值只允许放在配置文件中，禁止散落硬编码。
2. 先保证停/行稳定，再调行中子状态。
3. 每次调参都记录版本号和变更原因。

## 2. 参数建议（初版占位）

## 2.1 主状态（STOP / MOVE）
- moveEnterSpeedMps: 1.8
- moveExitSpeedMps: 1.0
- moveEnterHoldMs: 1200
- moveExitHoldMs: 2000
- hysteresisSpeedGap: 0.4

说明：退出阈值和退出时长更保守，避免红绿灯附近来回抖动。

## 2.2 行中子状态
- accelLongitudinalMin: 0.55
- brakeLongitudinalMin: -0.75
- turnYawRateMin: 18
- bumpVerticalEnergyMin: 1.2
- cruiseMotionVarianceMax: 0.35

说明：数值单位和最终范围以代码内实际计算口径为准，此处用于初始化。

## 2.3 子状态调度
- subStateMinHoldMs: 500
- subStateCooldownMs: 300
- priorityOrder: BRAKE > TURN > ACCEL > BUMP > CRUISE

## 3. 配置结构建议
```json
{
  "main": {
    "moveEnterSpeedMps": 1.8,
    "moveExitSpeedMps": 1.0,
    "moveEnterHoldMs": 1200,
    "moveExitHoldMs": 2000,
    "hysteresisSpeedGap": 0.4
  },
  "sub": {
    "accelLongitudinalMin": 0.55,
    "brakeLongitudinalMin": -0.75,
    "turnYawRateMin": 18,
    "bumpVerticalEnergyMin": 1.2,
    "cruiseMotionVarianceMax": 0.35
  },
  "scheduler": {
    "subStateMinHoldMs": 500,
    "subStateCooldownMs": 300,
    "priorityOrder": ["BRAKE", "TURN", "ACCEL", "BUMP", "CRUISE"]
  }
}
```

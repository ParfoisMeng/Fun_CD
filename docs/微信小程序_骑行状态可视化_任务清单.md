# 微信小程序：骑行状态可视化 Todo（单人 + AI 直推版）

## 1. 用法说明
- 这是给单人 vibe coding 用的清单。
- 你不需要做传统项目管理，只要按顺序把每个任务丢给 AI 执行。
- 每条任务都按这 3 步走：
1. 让 AI 先实现
2. 让 AI 自测并修复
3. 让 AI 回报改了哪些文件

## 2. 今日就能开工的主线（按顺序）

### [ ] A01 建立小程序最小骨架
目标：生成 3 个页面 `prepare`、`ride`、`result`，并打通路由。
完成标准：本地能打开 3 页并互相跳转。
可直接给 AI 的指令：
```text
请在当前项目创建微信小程序基础骨架，包含 prepare/ride/result 三个页面，保持结构清晰并可直接运行。完成后告诉我改动文件列表。
```

### [ ] A02 接入传感器采集
目标：统一采集定位速度、加速度、陀螺仪、姿态数据，输出标准帧。
完成标准：在 `ride` 页实时打印标准化 `SensorFrame`。
可直接给 AI 的指令：
```text
请实现传感器采集模块，输出统一结构的 SensorFrame（含时间戳、速度、accel、gyro、attitude），并接到 ride 页面实时更新。
```

### [ ] A03 做滤波和特征提取
目标：实现去噪和平滑，输出可用于状态判断的特征。
完成标准：可看到 `speedTrend`、`gyroYawRate`、`accelVerticalEnergy` 等字段稳定更新。
可直接给 AI 的指令：
```text
请实现 signal 层：滑动窗口 + 指数平滑 + 特征提取（speedTrend、accelLongitudinal、gyroYawRate、accelVerticalEnergy），并给出关键参数配置项。
```

### [ ] A04 实现停/行主状态机
目标：主状态只保留 `STOP` / `MOVE`，加防抖、滞回、最短保持。
完成标准：慢速抖动时不频繁来回切换。
可直接给 AI 的指令：
```text
请实现 STOP/MOVE 主状态机，包含进入阈值、退出阈值、滞回区间、最短保持时长，并接入实时数据流。
```

### [ ] A05 实现行中 5 子状态
目标：`ACCEL` `CRUISE` `TURN` `BRAKE` `BUMP`。
完成标准：能在模拟输入或实测中触发并显示当前子状态。
可直接给 AI 的指令：
```text
请在 MOVE 状态下实现 5 个子状态判定：ACCEL/CRUISE/TURN/BRAKE/BUMP，并输出状态与置信度。
```

### [ ] A06 加子状态优先级调度
目标：固定优先级 `BRAKE > TURN > ACCEL > BUMP > CRUISE`。
完成标准：冲突时输出唯一主子状态，不闪烁。
可直接给 AI 的指令：
```text
请实现子状态调度器，按 BRAKE > TURN > ACCEL > BUMP > CRUISE 选择当前子状态，并加入冷却时间与最短显示时间。
```

### [ ] A07 先做无素材版动画驱动
目标：不用美术资源，先用几何图形/占位块跑通演出逻辑。
完成标准：停/行 + 5 子状态在画面中有明显差异。
可直接给 AI 的指令：
```text
请先用占位图形实现 cat-stage 动画驱动：STOP 单脚撑地、MOVE 基础骑行、ACCEL 风线、TURN 车头偏转、BRAKE 前压/后翘、BUMP 抖动。
```

### [ ] A08 组装竖屏主页面
目标：完成“主舞台 + 状态条 + 数据条 + 结束按钮”布局。
完成标准：竖屏下角色区域占主视觉，状态文案 4-6 字可读。
可直接给 AI 的指令：
```text
请实现 ride 页面竖屏布局：上方主舞台、中间短状态条、下方数据条（速度/时长/趋势）、底部结束按钮，保持远看可读。
```

### [ ] A09 准备页与结束页打通
目标：准备页权限流 + 结束页统计展示。
完成标准：可以完整走完 prepare -> ride -> result。
可直接给 AI 的指令：
```text
请实现 prepare 页面权限引导与开始流程，并实现 result 页面展示时长、距离、速度摘要、事件计数，打通全链路跳转。
```

### [ ] A10 加日志导出与调参入口
目标：便于后续快速让 AI 调阈值。
完成标准：可导出最近一次骑行状态日志（时间戳 + 特征 + 主/子状态）。
可直接给 AI 的指令：
```text
请增加状态日志导出能力，记录时间戳、关键特征、主状态、子状态、置信度，并提供一个简单的调参配置文件。
```

```text
要求：

```

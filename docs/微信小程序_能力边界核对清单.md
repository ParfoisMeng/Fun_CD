# 微信小程序能力边界核对清单（开发前）

## 1. 目标
在正式写业务代码前，先确认微信小程序在目标机型上的传感器能力和限制，避免后续返工。

## 2. 必核对能力

### 2.1 定位与速度
- 是否能稳定获取位置更新
- 速度字段是否可用（低速时是否抖动明显）
- 城市高楼场景下是否存在明显漂移

### 2.2 加速度计
- 是否可持续监听
- 数据刷新频率大致范围
- 静止状态噪声水平

### 2.3 陀螺仪
- 是否可持续监听
- 转弯时 yaw 方向变化是否明显
- 数据是否存在断续跳变

### 2.4 姿态角（如可用）
- pitch/roll/yaw 是否可用
- 在车把固定场景下是否稳定

### 2.5 生命周期限制
- 切到后台后监听是否中断
- 锁屏后行为
- 回到前台后是否需重新订阅

1. 主状态判定不能只依赖 GPS 速度，必须融合运动特征。
2. 状态机要有防抖与滞回，禁止阈值硬切。
3. 所有传感器异常都要有兜底文案，不能让页面空白。

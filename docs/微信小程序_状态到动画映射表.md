# 微信小程序状态到动画映射表（V1）

## 1. 目标
将状态机输出统一映射到角色动作、特效、文案，防止逻辑层和表现层脱节。

## 2. 主状态映射

### STOP（等待启动）
- 基底动作：小猫单脚撑地，车静止
- 微动画：尾巴轻摆、呼吸起伏
- 文案：等灯中

### MOVE（行进）
- 基底动作：基础骑行循环
- 文案：前进中

## 3. 子状态映射（仅 MOVE 下）

### ACCEL（提速）
- 动作：身体轻前倾
- 特效：短时风线
- 文案：轻轻加速
- 强度参数：0~1 影响风线长度和前倾幅度

### CRUISE（平稳）
- 动作：低幅稳定骑行
- 特效：无或极轻
- 文案：平稳骑行

### TURN（转弯）
- 动作：车头偏转 + 身体侧倾
- 特效：无
- 文案：左转一下 / 右转一下
- 强度参数：按 yawRate 映射偏转角

### BRAKE（刹车/减速）
- 动作：前压或后翘（翘屁股演出点）
- 特效：刹车线/轻微摩擦
- 文案：刹一下
- 强度参数：按减速度映射动作夸张度

### BUMP（颠簸）
- 动作：高频小抖
- 特效：震动线
- 文案：路有点颠
- 强度参数：按垂向能量映射抖动幅度

## 4. 冲突处理
1. 同时命中多个子状态时按优先级出一个主子状态。
2. 低优先级状态只允许保留弱化特效，禁止抢主动作。
3. 状态切换时必须有最短显示时间，防止闪烁。

## 5. 文案白名单（短句）
- 等灯中
- 起步啦
- 平稳骑行
- 左转一下
- 右转一下
- 刹一下
- 路有点颠

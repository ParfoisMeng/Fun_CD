# 首轮原型：确认范围与实现

更新：2026-09-17。此文档是本轮实现基线，取代 2026-07-07 文档中关于完整 V1、三页面、五种子状态和两周排期的要求。

## 已确认的产品决策

- 根本目的为趣味陪伴。是否继续开发由用户自行实测决定，不建立产品效果验收门槛。
- 微信小程序，手机竖屏固定在电动车车把；优先适配 iPhone 17，iOS / 微信版本待真机记录。
- 小猫是有性格的伙伴，先通过动作同步建立联系。首轮不冻结性格，后续支持多种表现。
- 首轮仅起步、骑行、停车撑地，以及停车时东张西望 / 眨眼的小动作。转弯、颠簸、刹车专属演出及多角色留待后续。
- 使用流程：手持打开 → 安装到支架 → 点击开始 → 默认 2 秒倒计时并提醒尽量不要大幅动作 → 用期间传感器均值建立初始基准。不是单帧取值，也不要求完全静止才允许进入。
- 舞台提供重新校准；不自动猜测用户是否调整支架。
- 定位为开始感应的必要条件。仅前台采集，回到前台重新接收数据；校准被中断则重来。
- 起步较灵敏，停车更保守。短暂断流保留状态，超过有效期显示中性等待，恢复后继续。
- 首轮无骑行统计、结果页、历史骑行产品功能。调试记录文件列表不等同于历史骑行系统。
- 外场数据自动记录在本机，由用户主动导出；电脑导入回放、调参复测。两端使用同一个状态引擎和小猫渲染器。

## 感应和校准的实际含义

加速度单位 g；均值包含重力和安装倾角，并不能仅凭静态采样分离真实传感器偏置，更不能从静态数据推导车辆前进轴。首轮用当前向量与校准均值的差计算动作强度，不积分成速度。陀螺仪单位 rad/s，原样记录并保存校准均值，目前不参与停行判定。

定位速度指数平滑后进入带滞回的 STOP / MOVE 状态机。近起步阈值时，持续动作可辅助启动；静止 GPS 下的晃动不能独立触发 MOVE。停车要求低速、动作强度较低且保持较长时间。负速度、精度无效或精度差的定位不刷新有效期。定位或加速度过期都进入等待，不把“数据未知”伪装成 STOP。

业务主状态仍是 STOP / MOVE；ready、waiting、paused、calibrating、calibration-failed 为采集可用性状态，控制动画是否中性显示。参数均为初版假设，非 iPhone 17 实测结论。

## 记录与回放

- 事件按回调到达顺序记录，t 为会话开始后的毫秒数（系统时钟差值并保证不倒退），不是硬件采样时间；绝对开始时间保存在文件头。
- 定位回调包括经纬度、速度、精度等原始字段；无服务器上传。数据导出后由用户保管。
- 原始 accel / gyro / location 事件与 tick、校准、暂停、恢复、错误、结束事件一起保留；state 为当时派生结果。
- 每秒或满 150 行同步追加，退后台及退出主动 flush。进程被强杀可能丢失最后一批缓冲；解析器可恢复最后一行截断，明确提示记录不完整。
- 当前会话导出先 flush，再复制为稳定快照，采集可继续。旧记录在准备页仍可导出；不会自动覆盖已有 ride 文件。
- 电脑端支持导入、播放 / 暂停、倍速、拖动、时间线跳转、参数修改和导出。比较“原始判定 / 记录参数在当前引擎重算 / 当前参数重算”。版本不同时显示提示，不宣称历史引擎完全复现。
- JSONL 导入上限 50 MB。实际长时间采集的存储配额、写入耗时、导出上限仍需真机测量；磁盘写入失败会显式提示。

## 本轮完成标准与剩余验证

本地自动化验证覆盖均值校准、滞回和停行防抖、原始日志重算一致性、断流恢复、暂停期间无 tick、重新校准、存储失败与异步启动清理。浏览器验证演示加载、进度跳转、调参后差异、还原及播放。

未完成的外部验证：微信开发者工具真实编译、有效 AppID / 定位接口开通 / 隐私指引配置、iPhone 17 真机授权及传感器采样、系统锁屏与微信后台切换、真实日志经微信导出并在电脑导入、20 分钟性能与存储。此处不把 mock 或合成数据当成真机验收。

# 恢复说明：首轮原型

更新：2026-09-17。

已从文档准备推进到代码原型。请先读 README.md 和 docs/首轮原型_确认范围与实现.md，后者是最新需求基线。

现在可以运行 npm run replay，在电脑使用合成演示记录，或导入手机导出的 JSONL。小程序需配置真实 AppID、定位能力及隐私指引后用微信开发者工具编译和真机预览。

核心：趣味陪伴；准备页手动开始；默认 2 秒均值校准；前台停行同步；重新校准；手机记录导出；电脑回放调参。首轮不做结果页、骑行统计和五种子状态全套。

代码目录：miniprogram/、replay/、tools/、tests/。npm test 与 npm run check 执行本地检查。共享引擎位于 miniprogram/core/engine.js，修改后两端同步生效；同时更新参数版本并重放已有记录。

剩余工作在 docs/微信小程序_骑行状态可视化_任务清单.md：有效账号配置、开发者工具编译、iPhone 17 真实数据采集与导出、长时间性能。不要把合成演示和 mock 测试视为真机验收。
